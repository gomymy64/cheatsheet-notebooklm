📌 Пошаговая инструкция
Шаг 1

Установка скилла в Claude Code

Скачай файл скилла NotebookLM из папки с ресурсами. Открой Claude Code, перетащи файл в рабочую область.

  • Перетащи файл .md в окно Claude Code
  • Напиши промпт и нажми Enter
  • Claude сам скачает скрипты, установит все и настроит подключение
  • Разрешай выполнение команд когда попросит (Yes/Allow)
💬 Промпт
Выполни этот скилл
Шаг 2

Авторизация в NotebookLM

Claude Code откроет браузер - тебе нужно залогиниться в Google.

  • В открывшемся браузере войди в свой Google-аккаунт
  • Перейди на notebooklm.google.com
  • Убедись что видишь свои ноутбуки
  • Вернись в Claude Code и напиши что залогинился
⚙️ Если браузер не открылся - набери в терминале: nlm login
Шаг 3

Проверка подключения

Убедись что Claude видит твои ноутбуки.

💬 Промпт
Покажи заголовки моих последних трёх ноутбуков
Шаг 4

Подключение к Claude Cowork

Теперь делаем так чтобы NotebookLM работал и в браузерном Claude.

  • В Claude Code напиши промпт - он сгенерирует файл скилла и сохранит на рабочий стол
  • Открой Claude Cowork в браузере
  • Нажми + внизу слева → Skills → Manage Skills → Upload a skill
  • Загрузи файл с рабочего стола
💬 Промпт (в Claude Code)
Добавь NotebookLM как скилл для Co-work
Шаг 5

Глубокий ресерч (Enrichment)

Самая мощная фишка - Claude уходит в NotebookLM, загружает десятки источников и возвращает только выжимку. Ты не тратишь токены на обработку.

  • Открой проект в Claude Cowork (или Claude Code)
  • Напиши промпт
  • Подожди пока Claude создаст ноутбук и проанализирует данные
💬 Промпт
Создай новый ноутбук на основе всего что ты знаешь обо мне и этом разговоре, плюс весь контекст проекта. После этого дай мне 10 выжимок и 3 действия которые нужно сделать прямо сейчас
💡 Если deep research таймаутит - спроси: "Ты импортировал все результаты deep research?"
Шаг 6

Генерация ассетов (инфографики, видео, подкасты)

NotebookLM умеет бесплатно генерировать визуальный контент. Claude просто отправляет запрос и скачивает результат.

  • Напиши промпт после любого обсуждения
  • Подожди генерацию
  • Claude скачает готовый файл
💬 Промпт
Создай инфографику в NotebookLM по этим выжимкам - красивые цвета, премиум шрифты, и скачай мне
⚙️ Доступные форматы: инфографики, видео, подкасты, презентации, mind map, quiz, flashcards
Шаг 7

Настройка вечной памяти (Wrap-up)

После каждой большой сессии Claude сохраняет все важное в специальный ноутбук "Мозг" в NotebookLM.

  • Скачай файл "Wrap-up скилл" из папки с ресурсами
  • Загрузи его в Cowork: + → Skills → Manage Skills → Upload
  • В конце любой большой сессии напиши промпт
💬 Промпт
/wrap-up
💡 Система сама создаст ноутбук "Мозг" (если его нет) и сохранит туда саммари сессии
Шаг 8

Автоконсультация с "Мозгом"

Сделай так чтобы Claude автоматически обращался к твоей базе знаний при каждом вопросе.

  • Открой настройки проекта в Cowork (Instructions справа)
  • Добавь строчку из промпта ниже
  • Сохрани - теперь Claude сам ищет ответы в твоей базе одним запросом
💬 Инструкция для проекта
При ответах на вопросы о стратегии всегда консультируйся с ноутбуком "AI Brain" в NotebookLM
